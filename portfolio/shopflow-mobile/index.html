PROJECT 05 — MOBILE APPLICATION

ShopFlow Mobile.

A mobile shopping experience designed for everyday use.

ShopFlow is a React Native shopping-app project for Android, designed around simple shopping interactions, account access and communication with a backend.

EXPLORE THE CASE ↓

01 / OVERVIEW+

THE PROJECT

Understand the challenge.

A shopping app needs to keep account access, navigation and cart actions easy to understand. It also depends on secure backend connections and useful address information.

THE MAIN FOCUS

Building a practical mobile interface with connected account and shopping flows.

02 / EXECUTION+

HOW I APPROACHED IT

From idea to execution.

  1. 01

    Android experience

    Developed the React Native interface with an emphasis on clear navigation and responsive actions.

  2. 02

    Secure access

    Connected login, registration and user authentication to backend data.

  3. 03

    Shopping features

    Worked with cart changes, product bidding and Google APIs for address-related features.

TOOLS & TECHNOLOGIES

  • React Native
  • Android
  • Firebase
  • Google APIs
  • Authentication
