01 / OVERVIEW+

THE PROJECT

Understand the challenge.

The research group needed a straightforward way to manage seminar information and registrations. The application also had to organize event-related data for later tracking and reporting.

THE MAIN FOCUS

A maintainable full-stack system shaped by user feedback and incremental delivery.

02 / EXECUTION+

HOW I APPROACHED IT

From idea to execution.

  1. 01

    User experience

    Built a responsive React and TypeScript frontend for finding seminars and registering interest.

  2. 02

    Data and backend

    Used a Java Spring Boot backend with MySQL to support seminar registration and attendance data.

  3. 03

    Team delivery

    Worked in Scrum sprints, incorporating feedback from the research group and testing functionality.

TOOLS & TECHNOLOGIES

  • React
  • TypeScript
  • Java
  • Spring Boot
  • MySQL
  • REST APIs
  • Scrum
