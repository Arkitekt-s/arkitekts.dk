PROJECT 03 — GROCERY DELIVERY PLATFORM

Full-Stack Application.

A grocery delivery system connecting products, orders and drivers.

A full-stack grocery delivery project built around a Java backend and modern web frontend. It manages products, deliveries and van assignments through a relational database and REST APIs.

01 OVERVIEW 02 MY WORK 03 OUTCOME 04 LINKS
01 / OVERVIEW+

THE PROJECT

Understand the challenge.

The system needed to keep product information, delivery totals and vehicle limits consistent. Staff required a practical way to create orders, see what had been assigned and prevent deliveries exceeding van capacity.

THE MAIN FOCUS

A clear connection between frontend workflows, backend rules and stored data.

02 / EXECUTION+

HOW I APPROACHED IT

From idea to execution.

  1. 01

    Products and inventory

    Created product management features for adding, listing, searching, editing and removing products.

  2. 02

    Delivery workflow

    Supported multi-product deliveries with total price and weight calculations and delivery tracking.

  3. 03

    Capacity rules

    Added van assignment checks using each vehicle’s weight limits, alongside backend testing.

TOOLS & TECHNOLOGIES

  • Java
  • Spring Boot
  • Spring Data JPA
  • React
  • TypeScript
  • MySQL
  • REST APIs
03 / OUTCOME+

WHAT IT SHOWS

What the work delivered.

The project demonstrates a complete application flow: a React and TypeScript interface, Spring Boot business logic and MySQL persistence. Frontend and backend code are available in separate repositories.
